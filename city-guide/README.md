# Гид по городу

## Что потребуется

- компьютер с Windows 11;
- доступ к интернету для первой установки зависимостей;
- Node.js `v22.19.0` и npm, который устанавливается вместе с Node.js.

Проект проверялся с Node.js `v22.19.0`. Для максимально воспроизводимой установки используйте именно эту версию. Не нужно устанавливать Expo CLI или React Native CLI глобально: все команды ниже используют пакеты из проекта.

## Установка Node.js на Windows 11

1. Закройте открытые окна PowerShell, командной строки и встроенные терминалы в редакторах кода.

2. Откройте официальный архив Node.js: [nodejs.org/download/release](https://nodejs.org/download/release/).

3. Откройте папку версии `v22.19.0` и скачайте файл `node-v22.19.0-x64.msi`.

   `x64` предназначен для обычной 64-битной версии Windows 11. Не выбирайте `arm64`, если компьютер не использует ARM-процессор.

4. После завершения загрузки дважды щёлкните по файлу `node-v22.19.0-x64.msi`.

5. Если Windows попросит разрешение на изменение устройства, выберите **Да**.

6. В окне установки последовательно нажмите:

   1. **Next**;
   2. **I accept the terms in the License Agreement**;
   3. **Next**;
   4. **Next** на экране выбора папки установки. Оставьте папку по умолчанию `C:\Program Files\nodejs\`;
   5. **Next** на экране выбора компонентов. Оставьте включёнными `Node.js runtime`, `npm package manager` и добавление Node.js в `PATH`;
   6. **Install**;
   7. **Finish** после завершения установки.

   Предложение установить дополнительные инструменты для нативных модулей можно не выбирать: для этого проекта они не требуются.

7. Откройте новое окно **Windows PowerShell** через меню «Пуск». В уже открытом до установки терминале проверка может не сработать, потому что он ещё не получил обновлённый `PATH`.

8. Выполните команды:

   ```powershell
   node -v
   npm -v
   ```

9. Первая команда должна вывести `v22.19.0`. Вторая команда должна вывести версию npm. Если вместо этого отображается сообщение, что `node` или `npm` не является командой, закройте PowerShell, откройте его заново и повторите шаг 8. Если ошибка сохранилась, перезагрузите компьютер и повторите проверку.

## Установка проекта

1. Скопируйте или распакуйте папку `city-guide` в любое удобное место на диске.

2. Откройте PowerShell.

3. Перейдите в папку проекта. Например:

   ```powershell
   cd "C:\Users\user\Desktop\base\University\3 курс\ВЯП (ЛР)\прочее\city-guide"
   ```

   Если проект находится в другой папке, замените путь внутри кавычек на фактический путь к папке, в которой лежит `package.json`.

4. Убедитесь, что PowerShell находится в правильной папке:

   ```powershell
   Get-ChildItem package.json, package-lock.json
   ```

   Команда должна вывести оба файла. Если один из них не найден, вернитесь к шагу 3 и укажите правильную папку.

5. Установите версии зависимостей, сохранённые в `package-lock.json`:

   ```powershell
   npm ci
   ```

   Дождитесь завершения команды. Она создаст папку `node_modules`. Не запускайте `npm install` вместо `npm ci`: `npm ci` устанавливает зафиксированные версии зависимостей без изменения `package-lock.json`.

## Запуск в браузере

1. Оставаясь в папке проекта, выполните:

   ```powershell
   npx expo start --web
   ```

2. Дождитесь строки с адресом, обычно вида `http://localhost:8081`.

3. Если браузер не открылся автоматически, скопируйте этот адрес из PowerShell и вставьте его в адресную строку браузера.

4. Для мобильного вида откройте инструменты разработчика браузера, включите режим мобильного устройства и задайте размер области просмотра `360 × 800`.

5. Для остановки сервера вернитесь в PowerShell и нажмите `Ctrl + C`.

## Быстрая проверка исходного кода

Проверка TypeScript выполняется из папки проекта:

```powershell
npx tsc --noEmit
```

Успешное завершение без сообщений об ошибках означает, что TypeScript не обнаружил ошибок типов.

## Частые проблемы

### Команда `node` или `npm` не найдена

Откройте новый PowerShell после установки Node.js. Если не помогло, перезагрузите компьютер. Затем повторите `node -v` и `npm -v`.

### `npm ci` сообщает, что не найден `package-lock.json`

Команда запущена не в папке `city-guide`. Выполните шаги 3 и 4 раздела «Установка проекта».

### Порт уже занят

Expo может автоматически выбрать другой свободный порт. Откройте именно тот адрес `localhost`, который напечатан в PowerShell после запуска команды.
